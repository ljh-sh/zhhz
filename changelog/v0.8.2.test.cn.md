## v0.8.2 内容

包含三个连续的功能发布：

### v0.8.0 — detect TW/HK 分类器调优
- `滑鼠`（两岸通用）现在正确归类为 `cn-tw` 而非 `cn-t`。算法使用绝对
  短文字符数，对共享区域繁体短语默认归 TW。
- 新测试：`regional_shared_phrase_defaults_to_tw`。

### v0.8.1 — `--auto --target <REGION>`
- `--auto` 模式下可配置目标区域。默认仍为 cn-s。
- 支持常见 `from → target` 组合，对不支持组合（如 `cn-tw → cn-t`）
  给出清晰错误。
- 校验：`--target` 需要 `--auto`；与 `--to` 互斥。

### v0.8.2 — `zhhz info <CONFIG>`
- 新增自省子命令。打印 config 名、描述、源/目标区域、输入/输出示例。
- 纯 UI，不执行转换。

## 兼容性

库 API 不变。WASM / npm / PyPI 接口不变。
