# zhhz v0.8.1

**`--auto` 目标可配置**。`--auto` 之前总是转到简体 (`cn-s`)。
本版本新增 `--target <REGION>`，让用户可把 auto-detect 后的文本
转到任意支持的目标区域。

## 新增

### `--target <REGION>` (搭配 `--auto`)

```bash
# detect + 转到选定区域
echo '我買了滑鼠' | zhhz --auto --target cn-t
echo '我买了鼠标' | zhhz --auto --target cn-tw

# 默认 (cn-s) — 行为不变
echo '我買了滑鼠' | zhhz --auto       # 我买了鼠标
```

**`--auto` 支持的 `(from → target)` 组合**：

| target | from | 路径 |
|---|---|---|
| `cn-s` (默认) | `cn-s` | 直通 |
| `cn-s` | `cn-t` | `t2s` |
| `cn-s` | `cn-tw` | `tw2sp` (台湾短语感知) |
| `cn-s` | `cn-hk` | `hk2sp` (香港短语感知) |
| `cn-s` | `jp-t` | `t2s` |
| `cn-s` | `jp-n` | `jp2t` → `t2s` |
| `cn-t` | `cn-s` | `s2t` |
| `cn-t` | `cn-t` | 直通 |
| `cn-t` | `jp-n` | `jp2t` |
| `cn-t` | `jp-t` | 直通 |

**不支持**的组合（如 `cn-tw → cn-t`、`cn-s → cn-tw`）会给出清晰错误，
提示用户用 `--config + --from/--to`：

```
error: --auto does not support converting CnTw to CnT;
       use --config + --from/--to for that combination
```

转换核心（16 个 OpenCC 配置，与 v0.8.0 byte-identical）未变。
v0.8.0 的 detect TW/HK 调优也未变。

## 校验规则

`--target` 必须搭配 `--auto`。`--target` 与 `--to` 互斥
（`--to` 是显式 `--from/--to` 路由的**源端**目标，不是 auto 路由的目的端）：

```bash
$ zhhz --target cn-t input.txt
error: --target requires --auto

$ zhhz --auto --target cn-t --to cn-tw input.txt
error: --target conflicts with --to (use --target with --auto only)
```

## 测试

- 28 unit + 7 integration + 7 wasm + 1 cli = 43 tests pass。
- CLI 行为已验证：
  - `--auto` (默认): TW 输入 → cn-s ✓
  - `--auto --target cn-t`: cn-s 输入 → cn-t ✓
  - 不支持的组合: 给出清晰错误 ✓
