# zhhz v0.8.2

**自省子命令**。纯 UI 新增：`zhhz info <CONFIG>` 显示每个 OpenCC 配置
做什么，不执行任何转换。脚本里手动确认该用哪个 `--config` 或
`--from/--to` 时很有用。

## 新增

### `zhhz info <CONFIG>`

```text
$ zhhz info s2t
Config:      s2t
Description: Simplified to Traditional (OpenCC standard)
From:        cn-s
To:          cn-t

Example:
  in:  汉字计算机软件
  out: 漢字計算機軟體
```

```text
$ zhhz info tw2sp
Config:      tw2sp
Description: Traditional (Taiwan) to Simplified (with phrases)
From:        cn-tw
To:          cn-s

Example:
  in:  滑鼠 印表機 軟體
  out: 鼠标 打印机 软件
```

```text
$ zhhz info jp2t
Config:      jp2t
Description: Japanese Shinjitai (new) to Kyūjitai (old)
From:        jp-n
To:          jp-t

Example:
  in:  辻 蝋燭 弁当
  out: 辻 蠟燭 弁當
```

非法 config 名：

```text
$ zhhz info foo
error: unknown config 'foo'. Valid: s2t, t2s, s2tw, tw2s, s2hk, hk2s, s2twp, tw2sp, s2hkp, hk2sp, t2tw, tw2t, t2hk, hk2t, t2jp, jp2t
```

## 兼容性

- 转换核心未变。所有 `--config` 和 `--auto` 路径的输出与 v0.8.1 byte-identical。
- 公开 API 不变。`Cli` 上的新 `info` 字段是内部字段。
- WASM 绑定和 Python wheels 不变。

## 测试

- 43 tests pass（28 unit + 7 integration + 7 wasm + 1 cli）。
- CLI 已验证 `s2t`、`tw2sp`、`jp2t` 和非法名。
