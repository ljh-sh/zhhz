# v0.1.0

First usable release.

## Added

- Pure-Rust conversion engine reproducing OpenCC's pipeline: forward-maximum-
  match segmentation + ordered conversion chain, with the same `PrefixMatch`
  group semantics (highest-priority dictionary wins, then longest key).
- All 16 OpenCC configs: `s2t`/`t2s`, `s2tw`/`tw2s`, `s2twp`/`tw2sp`,
  `s2hk`/`hk2s`, `s2hkp`/`hk2sp`, `t2tw`/`tw2t`, `t2hk`/`hk2t`, `t2jp`/`jp2t`.
- OpenCC dictionary data (~1.3 MiB) embedded in the binary via `include_str!`;
  no runtime download, no separate data directory.
- `build.rs` deterministically reproduces OpenCC's five build-time-generated
  dictionaries (reversed variant tables, tofu-risk subset, regional-phrase
  projection) so `data/` stays a pure upstream mirror.
- `zhhz` CLI: stdin/file input, `--config`, `--dict` (custom dictionaries at
  highest priority), `--in-place`, `--list`, `--help`, `--version`.
- `Converter` library API with `Converter::with_custom(...)` for programmatic
  custom words.
- `scripts/sync-opencc.sh` to re-vendor upstream data at a pinned ref.
- CI, release (cross-build + cosign signing + crates.io), Scorecard, CodeQL,
  cargo-deny/audit workflows; reproducible pinned toolchain.

## Notes

- The CLI argument parser is hand-rolled (no `clap`) to keep the dependency tree
  and binary small.
- Static release binary is ~1.6 MB with all data embedded.
