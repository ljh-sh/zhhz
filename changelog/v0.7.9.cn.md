# zhhz v0.7.9

**CI plumbing fix。** 对用户可见的变化:无 (npm tarball 仍是 616 kB,Rust 核心、WASM API 都不变)。

## 修复

- `.github/workflows/wasm.yml` 的 `Publish to npm` 步骤:同时
  设置 `NODE_AUTH_TOKEN` env 和 `npm config set
  //registry.npmjs.org/:_authToken`,后者会写入 `~/.npmrc`。
  在 ubuntu-latest runner 上,只设 env var 会让 `npm whoami`
  返 ENEEDAUTH(npm 10.x 的 auth-precedence 在某些场景下 env
  var 不优先)。两个都设后,`whoami` 打印 `edwinjhlee`,
  `npm publish` 继续。
- 加了两行 debug `echo` 输出 token 长度 + 前 8 字符,以后
  "ENEEDAUTH with good token" 的失败能在 CI 日志里直接诊断,
  不会暴露完整 secret。

## 内部

- `Cargo.toml` 升到 `0.7.9`,这样 `v*` tag 才能重新触发 publish
  job(`npm publish` 拒绝覆盖同版本)。
- `Cargo.lock` 重新生成。
