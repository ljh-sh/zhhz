# zhhz v0.8.3

**CI / fuzzing 表面升级。** Rust 核心、npm 包、WASM API 无变化，二进制仍是 616 kB。

## 新增

- `.github/workflows/fuzz.yml` — ASan + MSan 矩阵，两个 fuzz target（`fmm_segment`、`convert_roundtrip`）。4 个 job 矩阵每天 17:04 UTC 跑一次，周日 00:04 UTC 兜底，`workflow_dispatch` 手动触发。
- `oss-fuzz/` 子树（与 `google/oss-fuzz/projects/zhhz/` 保持一致）：
  - `project.yaml` — language: rust, sanitizers: address|memory|undefined
  - `Dockerfile` — `FROM gcr.io/oss-fuzz-base/base-builder-rust`
  - `build.sh` — 用 `$SANITIZER` 编译每个 fuzz target，打包种子 corpus
- PR [google/oss-fuzz#16131](https://github.com/google/oss-fuzz/pull/16131) — 等 Google 审核。
- `workflow_dispatch` 的输入 `max_total_time`，可以按需触发更长的 fuzz 会话（300s+）来抓 repro。

## 修复

- Fuzz workflow 的 header check、license 前言、project config schema，以满足 google/oss-fuzz 的 bot（`project.yaml` 而不是 `project.yml`；`auto_ccs` 是 email 字符串列表）。
- 一个老 `convert_roundtrip · memory` 上的 MSan 假阳性（zhhz#77）— 看起来是某个特定 nightly 版本触发的，在当前 nightly 上无法复现。关闭为 not reproducible。PR #82 的更长 fuzz + 无条件 crash artifact 上传保证下次能找到。

## 备注

- UBSan 已从 GH Actions 矩阵中移除：rustc 在 nightly ~2024-11 之后把 `-Z sanitizer=undefined` 从接受值里去掉。UBSan 走 OSS-Fuzz 那边的工具链 pin。
