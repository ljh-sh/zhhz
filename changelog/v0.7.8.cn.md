# zhhz v0.7.8

**分发重点版本。**v0.7.7 的转换引擎现在通过 `npm install zhhz` 提供给
Node.js / 浏览器。`wasm-bindgen` 编译为 WebAssembly,OpenCC 词典嵌入
`.wasm`,包完全自包含。

## 新增

### npm 包（`npm install zhhz`）

同一转换引擎的 WebAssembly 编译版本,通过 `wasm-bindgen` 暴露给
JavaScript。`src/engine.rs` 的转换核心不变,所有配置的输出与 CLI
逐字节一致。

- `convert(text, config)` — 16 个 OpenCC 全部配置的一次性转换。
- `convert_with_custom(text, config, entries)` — 最高优先级注入自定义词。
  `entries` 同时接受数组形式(`[["软件","軟體"]]`)和字符串形式
  (`"软件 軟體|..."`,兼容 opencc-js `DictLike`)。
- `detect(text)` — 简繁/地区变体检测(`cn-s` / `cn-t` / `cn-tw` / `cn-hk` /
  `jp-n` / `jp-t`),返回 `{ region, confidence }`(0–100)。**zhhz 独有**
  —— opencc-js 没有等价接口。
- `listConfigs()` / `listLocales()` — 内省。
- `configForRegionPair(from, to)` — 语义化区域对解析为对应 OpenCC 配置名
  (例如 `(cn-s, cn-tw) → "s2twp"`)。
- `new Converter(config)` — 可复用工厂实例,带 `.convert` / `.convertWithCustom` /
  `.withCustom` / `.config`。
- `Converter.forRegion(from, to)` — 从语义化区域标志构建 Converter
  (与 CLI 的 `--from` / `--to` 对应)。

### 文档

- `docs/npm.md` — npm 完整参考(安装、ESM/CJS、配置表、自定义词示例、
  检测、内省、语义化区域、API 与 opencc-js 的对比表)。
- `examples/node-usage/` — 可运行 Node.js smoke(24 条断言覆盖全部
  导出 API;`cd examples/node-usage && npm start`)。

### CI

- `.github/workflows/wasm.yml` 扩展:
  - **wasm-pack 通过 `WASM_PACK_VERSION` 锁定 `v0.13.0`**,防止未来
    上游发布静默修改已发布产物。
  - **`publish-dryrun` job** 由 `workflow_dispatch` 触发,执行 bundler
    构建 + `npm pack --dry-run` + smoke 导入;立刻暴露缺失的
    `NPM_TOKEN`,而不是在 tag 推送时静默失败。
  - **Smoke 测试从 4 个 case 扩展到 24 个**,端到端覆盖全部导出 API。

## 变更

- `src/wasm.rs` — 新增 `Converter` 类、`listConfigs` / `listLocales` /
  `configForRegionPair`、字符串形式的自定义词典解析。所有新增均带
  `#[cfg(feature = "wasm")]` 限定,只触及 wasm 路径;原生 CLI /
  Rust 消费者路径(engine.rs、dict.rs、detect.rs)不变。
- `convert_with_custom` 的 `entries` 参数从 `Vec<JsValue>` 改为
  `JsValue`(单个 pair 数组)。这对 TypeScript 消费者更友好,也与
  opencc-js 惯例一致。原先传 pair 数组的调用方无需修改即可继续工作。

## 内部

- `.gitignore` — 新增 `pkg/` 和 `pkg-npm/`,防止本地构建的 wasm-pack
  产物被纳入版本控制。

## 兼容性

- **CLI**:完全兼容,同样的参数、同样的输出。
- **Rust 库**:不变。`Converter::new`、`Converter::with_custom`、
  `convert(text) -> String`、`detect_text(text)`、`Detection` 与 v0.7.7
  行为一致。
- **原生测试速度**:`cargo test --release --locked` 墙钟时间不变。wasm
  feature 是可选的,对原生构建零开销(暖缓存运行:1.81 s 对比 v0.7.7
  基线 2.06 s,均在噪声范围内)。
- **27 lib 单元测试 + 7 convert + 7 context + 1 doctest = 42 全过**
  (与 `changelog/v0.7.8.test.md` 一致)。

## 安装

```sh
# npm(新增)
npm install zhhz

# Cargo(不变)
cargo install zhhz --version 0.7.8

# 二进制(不变)
curl -L https://github.com/ljh-sh/zhhz/releases/latest/download/zhhz-x86_64-unknown-linux-musl.tar.xz | tar xJ -
```

## 没发布的

- 异步 / 流式 API(暂缓——WASM 字符串边界不便流式处理)。
- napi-rs 原生绑定(暂缓——只有在基准测试证明必要时才重新评估)。
- 跨平台预编译产物(`.node` 二进制;同上)。
- 修改 `convert_with_custom` 的 array-pair 形状(暂缓;当前形状可用)。
