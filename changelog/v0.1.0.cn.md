# v0.1.0

首个可用版本。

## 新增

- 纯 Rust 转换引擎，复刻 OpenCC 流水线：正向最大匹配分词 + 有序转换链，组匹配语义与 OpenCC 的 `PrefixMatch` 一致（最高优先级词典胜出，其次最长键）。
- 全部 16 个 OpenCC 配置：`s2t`/`t2s`、`s2tw`/`tw2s`、`s2twp`/`tw2sp`、`s2hk`/`hk2s`、`s2hkp`/`hk2sp`、`t2tw`/`tw2t`、`t2hk`/`hk2t`、`t2jp`/`jp2t`。
- OpenCC 词库数据（约 1.3 MiB）通过 `include_str!` 内嵌进二进制；运行时无需下载，也没有独立数据目录。
- `build.rs` 确定性重现 OpenCC 在编译期生成的 5 个词库（反序变体表、tofu-risk 子集、区域词投影），使 `data/` 始终是上游的纯净镜像。
- `zhhz` CLI：stdin/文件输入、`--config`、`--dict`（自定义词典，最高优先级）、`--in-place`、`--list`、`--help`、`--version`。
- `Converter` 库 API，含 `Converter::with_custom(...)` 支持编程式自定义词。
- `scripts/sync-opencc.sh`：按固定 ref 重新 vendor 上游数据。
- CI、release（交叉构建 + cosign 签名 + crates.io）、Scorecard、CodeQL、cargo-deny/audit 工作流；可复现的固定工具链。

## 备注

- CLI 参数解析手写实现（不用 `clap`），以压缩依赖树与二进制体积。
- release 静态二进制约 1.6 MB，已内嵌全部数据。
