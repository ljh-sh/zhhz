# zhhz v0.8.2

**Introspection subcommand.** Pure-UI addition: `zhhz info <CONFIG>`
shows what each OpenCC config does without performing any conversion.
Useful for hand-checking which config to pass to `--config` or
`--from/--to` in a script.

## Added

### `zhhz info <CONFIG>`

```text
$ zhhz info s2t
Config:      s2t
Description: Simplified to Traditional (OpenCC standard)
From:        cn-s
To:          cn-t

Example:
  in:  汉字计算机软件
  out: 漢字計算機軟體
```

```text
$ zhhz info tw2sp
Config:      tw2sp
Description: Traditional (Taiwan) to Simplified (with phrases)
From:        cn-tw
To:          cn-s

Example:
  in:  滑鼠 印表機 軟體
  out: 鼠标 打印机 软件
```

```text
$ zhhz info jp2t
Config:      jp2t
Description: Japanese Shinjitai (new) to Kyūjitai (old)
From:        jp-n
To:          jp-t

Example:
  in:  辻 蝋燭 弁当
  out: 辻 蠟燭 弁當
```

Invalid config name:

```text
$ zhhz info foo
error: unknown config 'foo'. Valid: s2t, t2s, s2tw, tw2s, s2hk, hk2s, s2twp, tw2sp, s2hkp, hk2sp, t2tw, tw2t, t2hk, hk2t, t2jp, jp2t
```

## Compatibility

- No conversion core change. Output for every `--config` and `--auto` path
  is byte-identical to v0.8.1.
- No public API change. The new `info` field on `Cli` is internal.
- WASM bindings and Python wheels unchanged.
