# zhhz v0.7.7

**性能专版。** 相比 v0.7.5 只有一处改动：`Converter` 内部
新增可复用 `Vec<u8>` arena buffer，消除每段 350K 次
`String::with_capacity` 分配。API 完全兼容 v0.7.5。

## 为什么

Sample-based profile（zhhz#32）显示 zhhz 在每个语料上
**CPU 都比 opencc 快**，但 wall-time 慢 2×。根因：
**allocator pressure** — 10 MB 输入触发 35 万次 malloc/free。
Arena buffer 直接消除。

v0.7.6 原计划含 cache-line Node 布局（zhhz#35 A），但它在
warm cache 语料上**反而退化**。v0.7.7 只发 arena 改动以避免
退化。后续 v0.8.x 将探索 **inline short values**（cold-cache
语料的正确修法）。

## Bug 修复

- `tail_n_chars` 在字符数 < n 时返回 `&s[s.len()..]`，在 news
  语料 trigram 路径上 panic（`prev_emit` 在 trigram 上下文
  中可能只有 1 char）。已加 early return guard。

## 兼容性

- 与 v0.7.5 drop-in 兼容
- `Dict::from_text`、`Dict::from_entries`、`convert(text) -> String`
  API 不变
- 27/27 unit tests 通过，doctest 通过，`diff_corpus` byte-identical
  vs v0.7.5

## 安装
